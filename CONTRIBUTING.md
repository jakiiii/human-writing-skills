# Contributing

Thanks for contributing to Human Writing Skills.

## What belongs here

Good contributions include:

- clearer writing rules
- better before/after examples
- platform-specific installation improvements
- support for additional AI assistants
- language-specific adaptations
- fixes for ambiguous or overly strict instructions

## Contribution principles

Please preserve the core goals of the project:

1. Improve clarity, specificity, and natural voice.
2. Preserve factual accuracy and the writer's intent.
3. Avoid fabricated anecdotes, statistics, credentials, or results.
4. Do not deliberately introduce spelling or grammar errors to make text appear human.
5. Do not frame contributions as guaranteed AI-detector bypass techniques.
6. Treat common AI-writing patterns as contextual signals, not absolute bans.

## Pull requests

Keep pull requests focused and explain:

- what you changed
- why the change improves the writing standard
- any tradeoffs or edge cases

If you add a new rule, include at least one example showing when it helps.

## Style

Use concise Markdown, clear headings, and practical examples. Avoid unnecessary promotional language.
